# Project Maintenance

A sovereign agentic environment for managing skill systems, architectural documentation, and tool integrations. This project optimizes for high-bandwidth logic processing within strict hardware and token constraints.

## 🚀 Core Protocol: ANTIGRAVITY

This project operates under the **ANTIGRAVITY Protocol**, a 3-layer execution framework:

1.  **Pre-Flight**: Systematic review of `roadmap.md` and `Future_Steps.md` before any action.
2.  **Halt Trigger**: Immediate execution stop if parameters (APIs, Data Sources, Payload shapes) are ambiguous.
3.  **Data-First**: Schemas are defined and locked before logic implementation.

### Caveman Communication
Communication follows the **ULTRA-terse** Caveman protocol:
- Drop articles, conjunctions, and pleasantries.
- Fragments mandatory.
- Syntax: `[thing] [action]. X → Y.`

## 🛠 Tech Stack & Constraints

- **Hardware**: Mac Air 2017 (i5, 8GB RAM, No GPU).
- **Database**: Local SQLite.
- **Storage**: All markdown state files (except this README) are stored in `Archives/`.
- **ML Policy**: **NO local ML/PyTorch.** All heavy lifting occurs via external APIs or deferred requirement specs.

## 📂 Project Structure

- `Archives/`: Core state, roadmap, and identity documentation.
- `Skills/`: **Global Skills**. Reusable agentic SOPs and modular logic units.
- `project-skills/`: **Local Skills**. Specialized skillsets categorized by domain.

## 🧠 Skill Hierarchy

To ensure modularity and high-speed retrieval, skills must be placed according to their scope:

### Global Skills (`/Skills/`)
Internal agent logic and cross-project SOPs.
- **Path**: `/Skills/[skill-name]/SKILL.md`

### Local Skills (`/project-skills/`)
Domain-specific logic for the current environment.
- **Path**: `/project-skills/[category]/[skill-name]/SKILL.md`
- **Current Categories**: `ai-rag`, `embedded-c`, `python-backend`, `ui-show-hn`.

## 🎯 Skill Tiers

- **S-Tier (Core)**: Goal parsing, Context selection, Planning, Verification.
- **A-Tier (Support)**: Tool routing, Root-cause debugging, Memory management.
