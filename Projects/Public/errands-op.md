# errands-op (op-list)

- **Repository URL**: https://github.com/seeramsujay/errands-op
- **Visibility**: Public
- **Tech Stack**: Flutter, Dart, Home Assistant WebSocket API, 2D Kalman Filter, VRPTW Solver, DAG Topological Sort
- **Description**: Offline-first, algorithmic errand routing engine. Bridges Home Assistant to-do lists, solves multi-stop Vehicle Routing Problems with Time Windows (VRPTW), prevents false GPS triggers with dual-ring hysteresis geofencing, and learns in-store aisle walk-orders through Feedback Arc Set cycle elimination and topological sorting.
