# 🎮 SimpleFunProjects: Retro CLI Interactive Entertainment Engines

SimpleFunProjects is a curated catalog of lightweight, zero-dependency Python terminal utilities designed for retro CLI game simulation and mathematical relationship calculations. Operating entirely within the standard Python runtime, these engines demonstrate clean algorithmic design and input-driven text formatting.

---

## 🏗️ System Flow & Architecture

All tools in the suite execute under a pure, low-compute CLI loop utilizing standard I/O stream structures:

```
        [ Terminal User Prompt ] ──► (Name & String Parameter Entries)
                     │
                     ▼
       ┌───────────────────────────────┐
       │   🐍 Python Core Library      │
       │                               │
       │  • Common-Char Cancellation   │
       │  • Weighted Character Tally   │
       │  • Multi-Stage Map Reductions │
       └───────────────────────────────┘
                     │
                     ▼
          [ Standard Output Stream ] ──► (High-Contrast ANSI Playback UI)
```

---

## ⚡ Key Persuasion Points & Features

- **FLAMES Relationship Engine (`FlamesCalculator.py`)**: A classic implementation of the relationship simulator (Friends, Love, Affection, Marriage, Enmity, Sister). It uses exact common-character subtraction vectors and cyclic index loops to map compatibility paths between named entities.
- **Love Percentage Decoder (`LovePercentage.py`)**: Computes character frequency maps over combined string arrays, generating weighted percentages through mathematical sum reductions.
- **Absolute Zero Dependencies**: Formulated using native Python standard libraries. Requires zero package managers (`pip`, `poetry`, `conda`), ensuring instantaneous runtimes on any POSIX-compliant machine.
- **Clean Educational Blueprints**: Programmed with strict PEP-8 compliance, clean variable scopes, and detailed control loops, serving as a clean reference for fundamental python scripting.
